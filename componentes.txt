1. Funcionamento dos componentes
Para cada componente utilizado no projeto, expliquem:

Como o componente funciona;
Como ele será utilizado no projeto;
Qual será sua função específica;
Quais informações ele receberá ou fornecerá;
Como ele se comunicará com o Arduino/ESP32 ou com outros componentes;
Se existem configurações ou cuidados necessários para sua utilização.
Evitem apenas copiar a definição encontrada na internet. A explicação deve estar relacionada à utilização daquele componente no projeto do grupo.

2. Integração dos componentes
Explique como os componentes irão trabalhar em conjunto.

O grupo deve descrever, por exemplo:

Qual componente inicia o processo;
Quais sensores serão responsáveis pela entrada de informações;
Como essas informações serão processadas pelo Arduino/ESP32;
Quais decisões o sistema deverá tomar;
Quais componentes serão acionados como resposta;
Como os diferentes componentes dependem uns dos outros.
O objetivo é demonstrar que o grupo compreende como as partes do projeto serão conectadas e integradas para realizar a função proposta.

4. Fluxograma de funcionamento
Criem um fluxograma que represente o funcionamento do projeto, desde sua inicialização até a execução de suas principais funções.

O fluxograma deve representar, quando aplicável:

Início do sistema;
Inicialização dos componentes;
Entrada de dados dos sensores;
Processamento das informações;
Decisões e condições;
Acionamento de componentes;
Saídas do sistema;
Repetições e ciclos de funcionamento;
Encerramento, quando houver.
Utilizem os símbolos adequados para início/fim, processos, decisões, entradas e saídas.
